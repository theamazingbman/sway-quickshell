# Minimal Fedora + Sway + Quickshell

This is my minimal Fedora + Sway install with the ButterSway Quickshell shell and no theme switching.

## Quick Install

```bash
git clone https://github.com/theamazingbman/sway-min03.git
cd sway-min03
chmod +x install.sh
./install.sh
```


## Quickshell edition

This branch integrates the ButterSway Quickshell shell and its Sway IPC backend. Theme switching and wallpaper-generated palettes are intentionally removed. See [QUICKSTART.md](QUICKSTART.md) for shortcuts and included features.
